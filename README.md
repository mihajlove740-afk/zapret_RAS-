🛠️ Как использовать
1️⃣ Первый запуск
bash
# Запусти с правами администратора
ПКМ → service.bat → Запуск от имени администратора
2️⃣ Установка Zapret как службы
text
В меню выбери:
1 → УСТАНОВИТЬ Zapret как службу
→ Выбери номер стратегии (1 или 2)
→ Готово! 🎉
3️⃣ Проверка интернета
text

4 → ПРОВЕРИТЬ интернет и диагностика
